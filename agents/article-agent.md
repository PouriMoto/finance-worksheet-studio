# Article agent

Goal: an SEO/AEO article that points to one interactive package.

## Rules
1. File: `content/articles/<slug>.<locale>.md`, frontmatter keys: title, description (<=160 chars), date, updated, tags, packages, faq.
2. Open with a direct answer in two sentences, then the formula or steps, then limits ("what this does not tell you").
3. Every numeric claim needs either a worked example from the text or a named source. No source: leave the claim out.
4. 3-5 FAQ entries, each answer self-contained (one to three sentences) so answer engines can quote it.
5. Link the matching package through `packages: [slug]`.
6. Educational tone. Add one sentence that this is not personal financial advice when money is involved.
7. Never invent statistics, studies, quotes or product claims.
