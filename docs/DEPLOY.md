# انتشار نسخه‌ی Local (بدون بک‌اند)

```bash
SITE_URL=https://your-domain.com npm run build     # خروجی: apps/web/dist
```
- خروجی کاملاً استاتیک است: روی Nginx، Netlify، Cloudflare Pages یا هر هاست فایل کار می‌کند.
- **HTTPS لازم است** (service worker و PWA فقط روی HTTPS ثبت می‌شوند).
- `SITE_URL` را حتماً بگذار (canonical، hreflang، sitemap، llms.txt از آن می‌آیند).
- `/` به `/fa/` یا `/en/` بر پایه‌ی زبان مرورگر هدایت می‌شود.
- هنگام به‌روزرسانی: در `apps/web/public/sw.js` مقدار `VERSION` را عوض کن تا کش قدیمی پاک شود.
- داده‌ی کاربر فقط در مرورگر خودش است؛ سرور هیچ داده‌ای نمی‌بیند. به همین دلیل بازخورد تستر را باید از راه دیگری (فرم، گروه) بگیری.
