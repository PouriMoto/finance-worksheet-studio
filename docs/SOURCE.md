# منشأ کد
این ریپو یک کپی یک‌باره از پروژه Hormat Studio (Learning Studio) است (zip «hormat-studio»، اکتبر ۲۰۲۶) و از آن جدا می‌شود. اصلاح باگ‌های بعدی را دستی منتقل کن.
نام پکیج‌ها (`@hormat/*`) عمداً عوض نشد تا بازنویسی ایمپورت‌ها خطای ناخواسته نسازد؛ در فاز بعدی و پس از سبز بودن تست‌ها قابل تغییر است.

## تغییرات فاز ۰ (کم‌ریسک)
- برند: نام اپ، manifest، رنگ اصلی (`--brand: #0F766E` برای کنتراست AA با متن سفید)
- کلیدهای ذخیره‌سازی: `fcity.v1` ، `fcity.theme` ؛ قالب پشتیبان: `fcity-backup`
- حذف پوشه `backend/` (PocketBase)
- افزودن workflow انتشار روی GitHub Pages
- هنوز **حذف نشده‌اند** (عمداً، تا ابتدا خط پایه سبز شود): `economy.ts`، `migrate.ts`، قفل Cloud، محتوای غیرمالی، استریک/نشان/اعلان
